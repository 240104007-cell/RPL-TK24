# Contribution Rules

1. Gunakan branch sesuai username mahasiswa, misalnya `bagas`.
2. Pull Request mahasiswa hanya boleh mengubah `students/<username>.php`.
3. Jangan mengubah file mahasiswa lain.
4. Jangan mengubah `api/index.php`, `vercel.json`, `index.html`, workflow, atau konfigurasi repository.
5. Jalankan `bash scripts/verify-submission.sh <username>` sebelum commit.
6. Dosen/reviewer yang melakukan merge ke `main`.
